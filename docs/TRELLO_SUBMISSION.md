**Fabien Lufbery — Job Hunter Agent for Fabien Lufbery**

Projet individuel pour l’Antigravity Developer Challenge. Il comprend un dashboard de recherche d’emploi, une extension Chrome Manifest V3 avec import assisté, un client France Travail v2, un moteur Gemini de notation CV–offre et un éditeur de candidatures intégrable à Gmail.

- GitHub : https://github.com/fabienlufbery-hue/job-hunter-agent-for-fabien-lufbery
- Vercel : https://job-hunter-agent-for-fabien-lufbery.vercel.app
- Rapport et preuves : `FINAL_REPORT.md` et `docs/COMPLIANCE_MATRIX.md` dans le dépôt.

La fiche officielle de France Travail indique que l’API Offres d’emploi v2 est en accès restreint. Le client implémente OAuth2, les filtres et la pagination, vérifiés sur des réponses simulées. Une habilitation est nécessaire pour une validation en direct. https://www.data.gouv.fr/dataservices/api-offres-demploi

Le sujet cite Gemini 2.5 Flash. Google a annoncé sa dépréciation et recommande Gemini 3.5 Flash-Lite comme remplacement. https://aistudio.google.com/docs/changelog#11-02-2026
